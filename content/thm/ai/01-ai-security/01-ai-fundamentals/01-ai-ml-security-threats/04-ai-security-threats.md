# AI security threats

> [ATLAS MITRE](https://atlas.mitre.org/) framework a help guide for AI Cyber threats

## vulnerabilities in AI models

- `prompt injection`: prompts are used to instruct the model on how to perform, prompt injection occurs when the original instructions provided to the model are overridden, often for malicious purposes such as disclosing more information than it should, or generating harmful content

- `data poisoning`: when an attacker manipulates the training data used to train an AI model so its generated output is incorrect or biased

- `model theft`: when an attacker gains unauthorized access to an AI model, this attack is possible by querying the API of the ML model they want to steal, then use the output to train a clone model that mimics the behavior of the original

- `privacy leakage`: when an AI model inadvertently revealing sensitive information about the data it was trained on, even if the data was supposed to be kept confidential

- `model drift`: a model's performance drift over time due to changes in the data or the environment surrounding it

## enhanced attacks

> AI models can be used to generate the following attacks

- malware
- deepfakes
- phishing
