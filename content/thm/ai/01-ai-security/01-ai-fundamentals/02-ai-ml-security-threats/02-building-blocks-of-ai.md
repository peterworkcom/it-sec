## ml algorithms

> ml algorithms are the mathematical methods used to learn patterns from data, consist of three key components:

- `decision process`: makes predictions or classifications based on input data
- `error function`: evaluates performance and provides feedback
- `model optimisation process`: fine-tunes the algorithm to minimize errors and improve accuracy

**this iterative process continues until the model reaches a satisfactory performance level**

> 4 types of ml algorithms

- `supervised learning`: labeled data to train models for classification or regression tasks, such as predicting house prices or identifying spam emails
- `unsupervised learning`: unlabeled data to discover hidden patterns, often using clustering, association, or dimensionality reduction techniques
- `semi-supervised learning`: using a small portion of labeled data to guide the learning process
- `reinforcement learning`: mimics human learning by rewarding correct decisions and penalizing mistakes

## neural networks and deep learning

> neural networks goal is to enable computers to behave like humans

> neural networks 3 main parts

- `input layer`: receives raw data
- `hidden layers`: process and refine
- `output layer`: produces the final prediction

> deep learning algorithm is a part of the neural networks what goal is to learn new data from unlabeled data, like recognizing a number on an image

- deep learning does not need labelled data
- machine learning need labelled data
