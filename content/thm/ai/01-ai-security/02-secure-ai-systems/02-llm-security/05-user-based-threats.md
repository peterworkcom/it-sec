# user based threats

> AI can be used to manipulate human trust and judgment

## LLM Powered Social Engineering

> `Target / Attack Surface`: Human cognition and decision-making

> `Input`: Contextual or personal information used to craft persuasive output

> `Output`: Manipulated users (phishing success, fraud, coerced actions)

- LLMs can make scams far more convincing than traditional phishing, an LLM can now generate spear-phishing emails that read exactly like a colleague or executive

## Trust Exploitation (LLM09:2025 - Misinformation)

> `Target / Attack Surface`: User trust and judgment

> `Input`: Confident but incorrect or maliciously framed prompts

> `Output`: Users accepting false, unsafe, or harmful information

- when developers are using an LLM as a coding assistant and the LLM hallucinates fake software package names or updates, if a certain model frequently hallucinates a package, an attacker can quickly publish a rogue package by that name
