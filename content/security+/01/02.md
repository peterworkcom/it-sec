#

## The CIA Triad

> confidentiality

- prevent information disclosure to unauthorized person/system
- use encryption, access control, authentication

> integrity

- information can not be modified without detection
- use hashing, digital signature, certificates, non-repudiation

> availability

- system and network must be up and running
- use redundancy, fault tolerance, patching

## Non-Repudiation

> proof of integrity

- in cryptography use hash to verify that data did not change
- if data changes hash changes
- hash only can tell if data changed, it does not identify

> proof of origin

- authenticating the source of the data
- use digital signature what uses a private key
- the private key (only known by the sender) can be authenticated by a public key

## AAA framework

**(identification -> like username, usually not secret)**

> Authentication

- prove your are, who you say you are
- like a password, or two factor login

- for systems (like a laptop) digitally signed certificate for the device
- this certificate comes from a **Certificate Authority** (CA)
- a device signed by the "same" CA as the organization, can be authenticated

> Authorization

- based on Identification and Authentication
- what access do you have

- big scale authorization work with an authorization model
- this defined by roles, organizations, attributes ...

> Accounting

- resources used
- login time, logout time, data traffic you made

## Gap analysis

- analysis of where an person/organization stands right now and where it would like to be in the near/distant future
- creating a baseline of the current state, by breaking down it to small components, so it can be measured more accurately what needs improvement
- a formal standard could be useful for these goals
- creating a gap analysis report about the state
