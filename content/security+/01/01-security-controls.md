# Control Type Examples

| Control Type | Technical              | Managerial                    | Operational                     | Physical                        |
| ------------ | ---------------------- | ----------------------------- | ------------------------------- | ------------------------------- |
| Preventive   | Firewall               | On-boarding policy            | Guard shack                     | Door lock                       |
| Deterrent    | Splash screen          | Demotion                      | Reception desk                  | Warning signs                   |
| Detective    | System logs            | Review login reports          | Property patrols                | Motion detectors                |
| Corrective   | Backup recovery        | Policies for reporting issues | Contact authorities             | Fire extinguisher               |
| Compensating | Block instead of patch | Separation of duties          | Require multiple security staff | Power generator                 |
| Directive    | File storage policies  | Compliance policies           | Security policy training        | Sign: Authorized Personnel Only |

> Technical -> automated systems (no human interaction)

> Managerial -> polices (technical with human interaction)

> Operational -> guard (physical with human interaction)

> Physical -> barriers / signs (no human interaction)
