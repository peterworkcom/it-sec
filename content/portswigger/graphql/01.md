# Lab Walkthrough: Accessing Private GraphQL Posts

Great, you already have the official steps. Let me break this into **clear, simple stages** so it's easy to follow.

---

## Part 1: Find the hidden post

**Goal:** Prove that a hidden blog post exists.

1. Open the blog page in Burp's browser
2. Go to **Proxy → HTTP history**
3. Look for the GraphQL request that lists blog posts
4. Check the post IDs in the response
5. Notice: **ID 3 is missing**
   - This is a strong sign of a hidden post

---

## Part 2: Check if introspection is on

**Goal:** See if the API will reveal its own schema.

1. Find the request: `POST /graphql/v1`
2. Right-click it → **Send to Repeater**
3. In Repeater, right-click the request body
4. Choose: **GraphQL → Set introspection query**
5. Click **Send**
6. Look through the response for a type called `BlogPost`
7. Confirm it has a field called `postPassword`

> This tells you the password field **exists**, even though it's not normally shown.

---

## Part 3: Get the hidden password

**Goal:** Use ID 3 to unlock the secret field.

1. Go back to the **same Repeater request** (or send a fresh one)
2. Click the **GraphQL tab**
3. In **Variables**, change `id` to `3`
4. In the **Query** panel, add `postPassword` as a field to return
5. Click **Send**
6. Copy the value in `postPassword` from the response

---

## Part 4: Finish the lab

1. Paste the password into the **Submit solution** box
2. Refresh the page if needed
3. Done ✅
