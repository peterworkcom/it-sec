# functions

> `functions` used to define a code blocks that would be used multiple times, to avoid repetition

```bash
#!/bin/bash

favorite_unit() {
    echo "zergling"
}

favorite_unit
```

- create a `function` by giving a name and a `()` after
- the code block that relates to the `function` is in the `{}`
- executing (calling) the `function` by its name
