# redirect operators

| operator     | descriptions                                   |
| ------------ | ---------------------------------------------- |
| `>`          | `stdout` to **file**                           |
| `>>`         | append `stdout` to **file**'s' end             |
| `&>` or `>&` | `stdout` and `stderr` to **file**              |
| `&>>`        | append `stdout` and `stderr` to **file**'s end |
| `<`          | **file** to `stdin`                            |
| `<<`         | block of text to `stdin`                       |
| `\|`         | `stdout` to `stdin`                            |
